【ルール】【Rules】

① 点線上に境界線を引き、盤面をいくつかのブロックに分割します。境界線を挟むマスどうしが同じブロックになることはありません。また、使わないマスはありません。

② 初めから出ている斜線は各ブロックの一番長い対角線（複数ある場合はすべて）です。ただし、対角線はその両端以外がブロック内部を通過するものだけを対象とし、ブロックの他の頂点やブロックの外部を通過するものは除外します。

① Draw partition lines along the dotted grid to divide the board into several blocks. Adjacent cells separated by a line cannot belong to the same block. No cells can be left unused.

② The pre-existing diagonal lines represent the longest diagonals of each block (all of them if multiple exist). However, this only applies to diagonals whose body passes entirely through the interior of the block, excluding those that touch other vertices or pass outside the block.

ルール②の補足（除外される対角線の例）Supplement for Rule ② (Examples of Excluded Diagonals)

以下のような対角線は除外され、これら以外の対角線の中で最長のものが黒い斜線として表示されます。

The following types of diagonals are excluded. The longest diagonal among the remaining valid paths will be displayed as the black line.

  • ブロックの外部を通過するもの。（赤楕円箇所）
  • ブロックの他の頂点を通過するもの。（赤丸箇所）
  • Those passing outside the block (Indicated by the red oval)
  • Those touching or passing through other vertices of the block (Indicated by the red circle)

🎬 例題の解き方

💡 例題解説Walkthrough Guide

初期状態で配置されている黒い斜線（以下、「鉱脈」）の長さに注目して、これ以上に長い対角線が同じブロックに内包されないようにブロックを分割していきます。

Focus on the lengths of the pre-drawn black diagonal lines (referred to as "Veins"). Divide the blocks carefully so that no longer valid diagonals can accidentally be formed within the same room.

ステップ1：1本の鉱脈が通過するマスはすべて同じブロック！Step 1: All cells crossed by a single Vein belong to the same block!

鉱脈が複数のブロックにまたがることはありませんので、1本の鉱脈が通過するマスには同じ色をぬってしまいます。同じ長さの鉱脈はルール上同じブロックに属する可能性がありますが、とりあえず別の色で塗ってしまうことをオススメします。後半で手が止まったときに、「もしやあの2ブロックは同じブロックだったのでは？」と振り返られるように脳みそにセットしておいてください。(例題の緑ブロックと赤ブロックがこれに該当しますが、これらが同じブロックだとa5が頂点でなくなるので、ここはすんなり別ブロックと判定ができます。)
また、E1やE2のように一つの色のマス(この場合、青のマス)に囲まれたマスは他の色になれないので、青で塗りつぶしてしまいましょう。

A single Vein can never span across multiple different rooms, so fill all cells crossed by one Vein with the same color first. Even if two veins of the same length might technically belong to the same room, we highly recommend coloring them differently for now. Keep it in mind so you can look back later if you get stuck. (In this example, the green and red blocks are separate because if they merged, corner 'a5' would no longer be a valid vertex).

Also, spaces completely enclosed by a single color like 'E1' or 'E2' (surrounded by blue) cannot take any other color, so paint them blue right away.

🎬 例題の解き方(ステップ1,2)How to Solve (Step 1,2)

ステップ2：外周に足を下ろす鉱脈からは境界線発生！Step 2: Veins anchoring to the outer perimeter generate absolute boundaries!

鉱脈の両端はその鉱脈を含むブロックの頂点にあたります。なので鉱脈が外周に足を下ろす場合、そこから境界線が発生します。例題のb1やd1のように、B1やC1のマスが何色になるか決まってない段階でも、b1b2、d1d2部分に境界線が引けます。

Both ends of a Vein correspond exactly to the vertices of that room. Therefore, when a vein touches the outer border of the grid, a definitive boundary line always stems from that vertex. Even if the colors of 'B1' or 'C1' are not yet decided, you can immediately draw lines along 'b1-b2' and 'd1-d2'.

ステップ3：鉱脈が1本しかないのに、長方形ができそうになったら回避！Step 3: Avoid creating full rectangles if they only contain a single Vein!

長方形ブロックは必ず2本の鉱脈をもつので、鉱脈が1本しかない場所が長方形になりそうな場所を探します。例題で言うと緑と赤のブロック。このまま閉じればどちらも長方形ブロック。ですがどちらも鉱脈は1本だけなので、どちらもこのまま閉じることはありません。まずB4のマス、ここが緑のブロックじゃないなら、即座にa1b5は緑のブロックの対角線になってしまいます。なのでB4は緑のマスとなります。同様に考えてD4は赤のマスになります。

A perfectly rectangular block will always require exactly two internal veins. Look for areas where a room might prematurely close into a rectangle with only one vein inside. In our example, if closed immediately, both the green and red rooms would become rectangles with only one vein, which violates the rule. Therefore, cell 'B4' must expand to green to prevent a premature close. Following the exact same logic, cell 'D4' must become red.

🎬 例題の解き方(ステップ3)How to Solve (Step 3)

ステップ4：空白で残るマスは無い！ということは？Step 4: No empty cells allowed! What does that imply?

ここで中級手筋。B1とC1のマスにご注目。B1が緑のブロックにならない、C1が青のブロックにならないことは言いました。ここで、B1のマスが青のブロックになりうるかを考えてみましょう。もしB1のマスが青なら、かならずD1のマスに青色で地続きになる必要があります。このとき青でないことが決まっているC1のマスはどうなるでしょう。緑のマスにも赤のマスにも地続きになれず、孤立してしまいます。ということはつまり、B1のマスは青のマスになれないのです。同様に考えて、C1のマスも緑のマスになれません。つまり、B1とC1は青にも緑にもなれず、もちろん色を塗らずに終わることもできず、その結果、これらは赤のマスとなります。

Now for an intermediate strategy. Focus closely on 'B1' and 'C1'. We know 'B1' cannot be green, and 'C1' cannot be blue. What happens if we try to make 'B1' blue? It would have to form a continuous chain all the way to 'D1' using blue. This would completely isolate 'C1', leaving it unable to connect continuously to either green or red. Therefore, 'B1' can never be blue. Applying the same logic, 'C1' can never be green. Since they can't be empty, 'B1' and 'C1' can only resolve to red!

🎬 例題の解き方(ステップ4,5)How to Solve (Step 4,5)

ステップ5：同じ色のマスは地続き！Step 5: Matching colored cells must form a single continuous path!

B1とC1に突然現れた赤のマス。下の方にある赤のマスに地続きでつながらなくてはなりません。ということはC3とC4は赤のマスにしておかないと地続きが叶わなくなります。ここでC2まで赤のマスにしてしまうと、このブロックは対角線d1c5も鉱脈として出ていないといけないブロックになってしまうので、C1は赤のマスではないということが分かります。また、C1を緑のマスにしてしまうとまた赤のマスが地続きにできなくなります。なのでC2は青のマス。あとは赤マスを地続きにしてすべてのブロックの形が決まります。

The red pixels newly placed at 'B1' and 'C1' must link continuously down to the lower red mass. To fulfill this, 'C3' and 'C4' must become red. If you paint 'C2' red as well, it would create an illegal block shape that requires an extra vein at 'd1-c5', which isn't on the board. Thus, we deduce 'C2' must become blue. The rest of the puzzle elegantly untangles by completing the continuous path of red cells!

🎮 KOMYAKU Player 操作方法KOMYAKU Player Controls

KOMYAKU Playerは、鉱脈地図の問題とカラーパレットと4つのボタン(Undo/Redo/Clear/Check)で構成されます。

KOMYAKU Player consists of the Komyaku Map puzzle grid, a color palette, and 4 functional buttons (Undo/Redo/Clear/Check).

🎨 1. 通常の色塗りモード（カラーパレット 1〜9番）1. Normal Coloring Mode (Palette 1-9)

カラーパレットには9つの色が用意されています。選択した色でマスを塗ったり白マスに戻したりできます。

The color palette offers 9 distinct colors. You can paint cells with the active color or erase them back to blank tiles.

  • 色塗り：盤面上のマスをタップ/クリックすると、カラーパレットで選択された色でそのマスが塗られます。スワイプ/ドラッグすると連続して塗ることができます。
  • 消しゴム：同じ色で重ね塗りをすれば白マスに戻せます。
  • Painting cells: Tap or click any cell to paint it with your active color. Drag or swipe across the grid to color multiple cells continuously.
  • Eraser: Overwriting a colored cell with the exact same color resets it back to a blank white cell.

✏️ 2. ユーザー境界線モード（カラーパレット 10番・白ペン）2. User Boundary Line Mode (Palette 10 / White Pen)

KOMYAKU Playerでは隣接マスが異なる色で塗られると自動的に境界線を描画しますが、そうでない場合に境界線だけを描きたいケースがあります。その他、問題を解く上でのメモとして補助記号を用意しています。

KOMYAKU Player automatically draws border lines when adjacent cells have different colors, but you can manually draw lines if needed. It also features helpful sub-markers for note-taking.

📏 境界線を引くDrawing Room Boundaries

マス境界線の交差点(格子点)を始点にタテヨコにスワイプ/ドラッグすると、マス境界線上にブロック境界線を引くことができます。再度同じ場所をスワイプ/ドラッグすれば消去できます。
※ブロック境界線の両側のマスがすでに塗られている場合、そのブロック境界線は消去できません。

Swipe or drag horizontally/vertically from any grid vertex intersection to manually place block boundaries. Swipe over an existing manually-drawn line again to erase it.
*You cannot erase boundaries if the cells on both sides are already painted.

❌ 「✕」マーク"X" Memo Mark

マスの四辺の中央付近をタップ/クリックすると、「✕」マークを配置できます。ブロック境界線が引けないことが確定した場所に補助記号としてお使いください。再度タップ/クリックすれば消去できます。

Tap or click near the center of any cell's edge to place an "X" mark. Use this note marker where you are absolutely certain a room boundary line cannot pass. Tap it again to clear it.

❓ 「？」マーク"?" Memo Mark

マスの中央付近をタップ/クリックすると、「？」マークを配置できます。色を仮置きする場合などに補助記号としてお使いください。再度タップ/クリックすれば消去できます。

Tap or click near the dead center of a cell to drop a "?" mark. Excellent for keeping tabs on spaces where colors are temporarily placed as a guess. Tap again to clear.

✏️ 3. オレンジアシスト線3. Orange Assist Guide Lines

通常の色塗りモードで格子点(マス境界線の交点)を始点にドラッグするとオレンジ色の線が引けます。線の中央には線の長さを表す数値が表示され、各鉱脈の長さも同時に表示されるので、注目している格子点間の距離が注目している鉱脈よりも長くないかのチェックに使えます。また、注目している格子点間を結ぶ線がどのマスを通過するかも併せて確認することができます。
※各線の中央に表示する数値は、マス1辺の長さを1としたときの、各線の長さの2乗の値です。2乗しているのは整数値にするためで、線の長さの比較にはそのままお使いいただけます。

In normal coloring mode, dragging from a grid intersection draws an orange guide line. A number showing the distance's squared value appears in the middle, while checking if the current path outgrows the vein length. It also previews exactly which cells the straight line path crosses over.
*The displayed number represents the squared length of the line (with 1 cell unit = 1). Keeping values squared avoids decimals, providing an intuitive, direct integer comparison tool for diagonals.

🔄 4. 手戻し/やり直し（Undo / Redo）4. History Management (Undo / Redo)

その問題に対するすべての操作を手戻し/やり直しできます。

Seamlessly step backward (Undo) or forward (Redo) through all coloring, line-drawing, and memo marking operations performed on the active puzzle.

🗑️ 5. 盤面初期化（Clear）5. Clear Board Initialization

その問題を解く前の状態に初期化できます。
※間違って押してしまった場合はUndoボタンで戻れます。

Instantly wipes all grid colors, custom boundary lines, and note markers, completely resetting the board back to its initial blank problem state.
*Accidentally cleared the board? Just click the Undo button to recover everything safely.

💯 6. 正誤判定（Check）6. Solved Verification & Grading (Check)

ブロック境界線がすべて正しく引かれれば自動的に正解アニメーションが再生されます。もしすべて解き終えたはずなのに正解アニメーションが再生されない場合に押すと、不正解理由にあたる部分が赤マークで強調表示されます。
※もし解き終えて正解アニメーションが自動的に再生されない状況で、Checkボタンを押しても何も強調表示されない場合は、重解の可能性がありますのでお知らせいただけますと助かります。

When the grid lines perfectly partition the solution, the celebratory win animation launches automatically. If you feel you have finished but the game doesn't trigger the success animation, click Check to reveal errors highlighted in red markings.
*If your solution fails to auto-complete and pressing Check shows no red markings, a rare duplicate alternative solution might exist. Please contact us if this happens!
